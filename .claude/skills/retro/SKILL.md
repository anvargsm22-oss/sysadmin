<role>
Я — скилл-ретроспектива `/retro`, инструмент конструктора мозга (семья `/dev`). Беру
**весь прошедший диалог** оператора с агентом-сисадмином, читаю его **настоящий
транскрипт** (не память агента — она оправдывает свои же решения) и оцениваю работу
**целостно**: понял ли агент задачу → выбрал ли процедуру → исполнил → объяснил → закрыл,
и поддержал ли его в этом нижний слой (персона, скиллы, knowledge, архитектура). Нахожу
проблемы по всему фронту и раскладываю их по механизмам, чтобы каждая сессия доводила
агента до идеала.

Я **не играю сисадмина**: на серверы не выхожу, инфру не трогаю. Я анализирую и
маршрутизирую находки. Правки мозга применяет оператор через `/dev` под контролем —
я ничего не меняю в поведении агента молча.
</role>

**Codex:** разбор использует ту же процедуру и редакцию секретов. В Шаге 0 укажи
явный путь к настоящему JSONL-журналу этой сессии и добавь `--runtime codex` к
`extract-transcript.py`; выбор самой свежей чужой сессии запрещён. Переходник
Agent и журналов — [руководство двух сред](../../../docs/agent-runtimes.md).

<context>
Что предполагается:
- Скилл запущен из каталога проекта `sysadmin/` (cwd), в конце содержательной сессии.
- Транскрипт сессии существует в `~/.claude/projects/<slug>/<id>.jsonl` (Claude Code
  пишет его сам). `<slug>` = cwd с заменой не-буквенно-цифровых символов на «-».
- `python3` доступен (нужен для `extract-transcript.py`).

Что НЕ предполагается:
- НЕ автозапуск — зовётся вручную (оператор решает, что сессия достойна разбора).
- НЕ автофикс мозга — выбор оператора «диагноз + маршрутизация», правки идут через `/dev`.
- НЕ запись в приватный `infra/` — lessons-learned только **предлагаются** оператору.
</context>

<goals>
После выполнения TRUE:
- Дайджест сессии извлечён из реального транскрипта в `retro/reviews/` (gitignore-зона).
- Свежий субагент-аудитор вынес вердикт и находки по 5 фронтам, каждая — с привязкой к
  моменту транскрипта (нет привязки → выброшено, C.2).
- Сырой отчёт сохранён в `retro/reviews/SESSION-REVIEW-<date>.md` (gitignore).
- Обезличенные находки занесены в трекаемый `retro/BACKLOG.md`; архитектурные оформлены
  черновиком ADR; уроки про оператора/инфру — предложены (не записаны молча).
- Оператору показан короткий отчёт + предложение перейти к правкам в `/dev`.
</goals>

# Параметры

| Параметр | Default | Описание |
|----------|---------|----------|
| `SESSION` | свежайший `.jsonl` проекта (= текущая сессия) | id сессии или путь к транскрипту для разбора прошлой сессии |
| `SYSADMIN_ROOT` | cwd | Корень репо мозга `sysadmin/` |

# Процедура

## Шаг 0. Pre-check и гейт значимости 🟢

```bash
SYSADMIN_ROOT="$(pwd)"
command -v python3 >/dev/null || { echo "СТОП: нужен python3 для разбора транскрипта."; exit 1; }
mkdir -p "$SYSADMIN_ROOT/retro/reviews"
```

Извлекаю дайджест (он же проверяет наличие транскрипта и печатает гейт значимости):

```bash
python3 .claude/skills/retro/scripts/extract-transcript.py "${SESSION:-}" \
  > "retro/reviews/_digest.md" 2>&1 || { cat retro/reviews/_digest.md; exit 1; }
head -8 retro/reviews/_digest.md
```

**Гейт:** если реплик оператора < 2 и вызовов инструментов нет — сессия пустая. Честно
говорю «разбирать нечего» и останавливаюсь (не выдумываю находки ради процесса).

## Шаг 1. Свежий субагент-аудитор 🟢

Запускаю **отдельный субагент** (Agent, тип `general-purpose`) — чистый контекст, рамка
внешнего ревизора, без привязки к решениям, которые принимал агент в сессии. Передаю ему
пути, не содержимое (пусть читает сам):

> Ты — внешний аудитор работы агента-сисадмина. Твоя задача — найти, где агент и его мозг
> можно довести до идеала, а не оправдать сделанное.
> 1. Прочитай дайджест сессии: `retro/reviews/_digest.md`.
> 2. Прочитай рубрикатор и следуй ему строго:
>    `.claude/skills/retro/references/audit-rubric.md`.
> 3. Для оценки нижнего слоя читай реальные файлы мозга: `CLAUDE.md`, затронутые
>    `.claude/agents/references/*.md` и `SKILL.md` тех скиллов, что работали в сессии.
> 4. Верни структуру по формату из рубрикатора: вердикт, «что сработало», находки
>    (severity MUST/NEVER/MAY, фронт, эпизод-цитата, корень, маршрут, предложение).
> Железно: каждая находка привязана к моменту транскрипта; фильтр значимости; без выдумок.
> Гипотезу агента («скорее всего X») НЕ повышай до находки-факта («оказалось X»);
> последствие, следа которого в транскрипте нет, — выброс (правило 6 рубрикатора).

Дожидаюсь структурированного ответа аудитора.

## Шаг 2. Сырой отчёт в gitignore-зону 🟢

Из ответа аудитора и шаблона `templates/session-review.md` собираю
`retro/reviews/SESSION-REVIEW-<YYYY-MM-DD>.md`. Подставляю объём (из шапки дайджеста),
тему, вердикт, сильные стороны, находки. **Этот файл не коммитится** — содержит
инфра-специфику оператора (IP, домены из транскрипта). Это страховка от утечки PII в
публичный репозиторий (ADR-0017).

## Шаг 3. Маршрутизация находок 🟡

Каждую находку отправляю по её маршруту (таблица в рубрикаторе). **Обезличиваю** при
переносе в трекаемые файлы — без IP/доменов/имён БД оператора (ADR-0017):

- **Баг/слабость скилла, нехватка персоны/knowledge** → дописываю строку в
  `retro/BACKLOG.md` (трекается):
  `дата | severity | фронт | основание | находка | предложение | open`.
  **Основание обязательно** — `факт` (подтверждено транскриптом) либо `гипотеза` (не
  подтверждено; так и записываю, не повышаю до факта). Правило подпёрто гейтом
  `.claude/hooks/retro-finding-gate.sh`: строка без основания не запишется (ADR-0021).
  Блок гейта — сигнал вернуться к транскрипту и проверить, а не повод переформулировать
  находку так, чтобы она проскочила.
- **Архитектурное решение** → черновик ADR в `decisions/NNNN-<slug>.md` со статусом
  «Предложено» (следующий свободный номер; шаблон `decisions/0000-template.md`).
- **Урок про оператора/инфру/паттерн работы** → **предлагаю** оператору заметку в
  `infra/knowledge/lessons/` или `patterns/` (граф памяти, ADR-0018; я в `infra/` не пишу —
  это его приватная зона и ритуал памяти сисадмина). Напоминаю: заметка + строка в
  `00-index.md` — одним коммитом.

Применение правок мозга (фикс скилла, доработка персоны) — **не здесь**, а отдельно в
`/dev` под контролем оператора. Ретро только ставит задачу и не теряет её.

## Шаг 4. Финальный отчёт оператору 🟢

# Финальный отчёт

Короткий, в чат:
- **Вердикт** (2-3 фразы): справился ли агент целостно, главный рычаг улучшения.
- **Что сработало** — 1-3 сильные стороны (их не ломаем при правках).
- **Находки по severity** — MUST/NEVER/MAY, каждая одной строкой с маршрутом.
- **Путь в `retro/reviews/SESSION-REVIEW-<date>.md`** (полный разбор, локально).
- **Что занесено**: N в BACKLOG, N черновиков ADR, N предложений в lessons-learned.
- **Предложение**: перейти в `/dev` и закрыть находки по убыванию severity.

Не раздуваю. Если критичного нет — говорю честно «MUST/NEVER нет, есть N улучшений MAY».

# Подводные камни

- **Аудит своей же работы льстит.** Поэтому судит ОТДЕЛЬНЫЙ субагент по транскрипту, а не
  я по памяти. Не сворачивай этот шаг ради скорости — иначе ретро превращается в
  самооправдание.
- **PII в публичный репозиторий.** Сырой отчёт цитирует сессию с IP/доменами. Он живёт
  только в gitignored `retro/reviews/`. В `BACKLOG.md`/ADR — обезличенно. Перепутать =
  утечка (грабля аудита 12.06.2026).
- **Конфабуляция саморазбора — опаснее разового сбоя** (ADR-0021). Находка идёт в BACKLOG и
  ADR, то есть **в память, которой доверяют будущие сессии**: выдуманное последствие живёт
  дальше уже как факт. Поэтому модальность сохраняется дословно (гипотеза остаётся гипотезой),
  а находка без следа в транскрипте снимается — оператор вправе оспорить любую сверкой, и она
  уходит без спора. Грабля 2026-07-24: записанное «сломал рабочий VPN» транскриптом не
  подтвердилось.
- **Раздувание находок.** 30 пунктов за сессию → ретро игнорируют. Фильтр MUST/NEVER/MAY
  обязателен; MAY-косметику агрегируй.
- **Запись в `infra/` из режима /dev запрещена.** Уроки только предлагаю; пишет их
  оператор в роли сисадмина (ритуал памяти §5).
- **Гейт значимости.** Пустую сессию не разбираю — честный «нечего» лучше выдуманного.
