# 0041: Claude Code и Codex используют один мозг Sysadmin Agent

**Статус:** Принято
**Дата:** 2026-10-07
**Автор:** Codex, по разрешению оператора на полную адаптацию с сохранением Claude Code

## Контекст

Персона, навыки и хуки проекта загружаются из соглашений Claude Code. Пользователь
разрешил адаптацию к Codex и указал, что будет использовать обе среды. Codex
обнаруживает AGENTS.md, .agents/skills и собственные конфиги/хуки. Формат его
журналов отличается; роль user в response_item не доказывает голос оператора.

## Решение

Сохраняем CLAUDE.md, .claude/skills, knowledge, agent-config и приватную инфру как
общие источники. AGENTS.md и docs/agent-runtimes.md задают переходник Codex.
scripts/sync-codex.py генерирует точки входа навыков, профиль sysadmin и конфиги
Codex без персональных путей, моделей и расширения полномочий среды.

Codex-переходник нормализует поддерживаемые журналы и apply_patch, затем вызывает
существующие три Bash-хука. Политики не копируются в другой язык. Подтверждения
принимаются только из event_msg/user_message основной сессии; неизвестные форматы
не открывают красную зону. Ретроспектива использует тот же нормализатор и редакцию
секретов. Связность генерируемых файлов проверяется офлайн.

## Последствия

- Claude Code сохраняет существующий вход и поведение. Исправления общей политики
  применяются в обеих средах.
- Для Codex доступны те же навыки и тот же inventory, без символических ссылок
  Windows и без дублирования процедур.
- После изменения источников нужна регенерация. После изменения хуков Codex требует
  повторного доверия к их определениям.
- Переходнику нужны Python и Bash. Проверены наблюдаемые JSONL-формы Codex 0.160.0;
  нестабильный формат журнала требует тестов при обновлении движка.
- Локальные хуки не гарантируют покрытия облачной оркестрации, интерактивного stdin
  или всех MCP-путей. Полномочия и процедуры зоны остаются обязательными.
- Две среды могут читать одну инфру, но изменение одного сервера/рабочего дерева
  выполняется последовательно, с проверкой контекста другой сессии.
